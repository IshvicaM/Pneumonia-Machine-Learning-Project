# Pneumonia-Machine-Learning-Project
The main objective of this project was to train a Machine Learning (ML) model to identify pneumonia or normal in chest x-rays. In order to achieve this, I used the Chest X-Ray Images (Pneumonia) dataset and DenseNet121. During the journey to my final goal, I completed smaller scale ML projects to learn the concepts and necessary frameworks needed to achieve the final product.

Step 1) Coding a CNN to Analyse the MNIST Dataset

The main objective of this step was to train a ML model able to identify the different numbers within the MNIST dataset.

- Overview of Learned Machine Learning Frameworks/Topics: TensorFlow, Google Colab, Loss Metrics



Step 2) Coding a CNN that Predicts Whether an Image is a Cat or Dog

The main objective of this step was to train a ML model to learn the difference between cats and dogs in a dataset.

- Overview of Learned Machine Learning Frameworks/Topics: Google Colab, TensorFlow, Keras, OpenCV, Numpy, Matplotlib, Image preprocessing, Dataset preparation, CNN Architecture, Model Training, Management, Inference, Evaluation




Step 3) Using a Pre-trained Model (DenseNet121) to Analyze the Chest X-Ray Images (Pneumonia) Dataset 

The main objective of this project was to use a pre-trained ML model to identify the difference between pneumonia and normal chest x-rays using transfer learning.

- Overview of Learned Machine Learning Frameworks/Topics: Augmentation and Normalization, ImageNet Dataset (over 14 million annotated images which helps models learn features for general image recognition), Transfer Learning (removing top layer, adding different layers, freezing the base layers so the network only updates the weights in the new and untrained layers), Visualization of training and results 




Chest X-Ray Images (Pneumonia) dataset:

Kermany, Daniel; Zhang, Kang; Goldbaum, Michael (2018), “Labeled Optical Coherence Tomography (OCT) and Chest X-Ray Images for Classification”, Mendeley Data, V2, doi: 10.17632/rscbjbr9sj.2
